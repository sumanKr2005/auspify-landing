## ✨ Features

- Sticky navigation bar with mobile hamburger menu

- Infinite scrolling marquee ticker
- Why Us section with 4 feature cards

- Domains grid with 8 skill cards
- Testimonials section with 3 intern reviews
- FAQ accordion section
- CTA section
- Footer with scroll-to-top button
- Animated gradient background blobs
- Custom cursor glow
- 3D tilt effect on cards
- Scroll-reveal animations
- Animated number counters
- Glassmorphism UI with neon accents
